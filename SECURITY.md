# Security

This app runs a real local shell as you. Treat it like Terminal.app.

- Session notes and folder paths stay on your Mac (`~/Library/Application Support/Terminal Organizer/`).
- Nothing is uploaded.
- The Grok hook, if you use Grok, only asks the app to show a notification.

## Report a vulnerability

Open a [GitHub issue](https://github.com/jvjinfinity/terminal-organizer/issues) if it is safe to describe in public. For something that should stay private, email the maintainer listed on the GitHub profile.

Please do not file “Mac says this app is damaged” as a vulnerability. That is Gatekeeper blocking an ad-hoc signed build — see the README.
