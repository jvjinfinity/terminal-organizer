Put this on your Mac.

Terminal Organizer is a Finder-shaped app: a left list of terminal sessions (folder, git branch, a note for what that session is for) and a real local shell on the right. Free to use. You compile it on your machine — no App Store, no paid Apple developer certificate.

Install

1

Install Apple’s command-line tools

Open Terminal.app and run this. Click Install in the dialog, then wait until it finishes.

xcode-select --install

Already have Xcode from the App Store? You still need a recent version (16 or later). Check with swift --version — you want Swift 6.2 or newer.

2

Clone the project

git clone https://github.com/jvjinfinity/terminal-organizer.git
cd terminal-organizer

Or with the GitHub CLI: gh repo clone jvjinfinity/terminal-organizer

3

Build and put it in Applications

./scripts/install.sh

That compiles a Release build, copies /Applications/Terminal Organizer.app, and opens it. The first run fetches the SwiftTerm dependency — give it time.

4

First launch

macOS may warn that the app is from an unidentified developer. That is expected: this project does not pay for an Apple Developer certificate. You built the binary on this Mac.

If it is blocked: Finder → Applications → Terminal Organizer → right-click → Open → Open. Or run xattr -cr "/Applications/Terminal Organizer.app" and try again.

If it asks to send notifications, click Allow if you want pings (including from Grok). Optional. Do not set Grok’s notification method to osc777.

Using it

Click + (or ⌘N) for a session in the current folder, or ⌘⇧N to pick a folder. Click add a note (or ⌘E) and type what that session is for. Drag a row onto another to reorder.

KeyAction
⌘NNew session in the current folder
⌘⇧NNew session, pick a folder
⌘DDuplicate session
⌘WClose session
⌘EEdit the note
⌘RRestart that shell
⌘⇧RReveal folder in Finder
⌘ / ⌘- / ⌘0Font size
⌘1–9Jump to a session

Sessions (folder + note) live only on your Mac, in ~/Library/Application Support/Terminal Organizer/. Live shells do not survive quitting the app; the list comes back on relaunch as new shells in those folders.

Update later

cd terminal-organizer
git pull
./scripts/install.sh

Install replaces the running app. Live shells will not resume; folders and notes will.

If something fails

xcode-select or swift not found

Run xcode-select --install and wait until it completes. Then open a new Terminal window and try swift --version.

Xcode license

If the build stops on a license prompt:

sudo xcodebuild -license accept
Build cannot fetch SwiftTerm

You need network access to GitHub. First build downloads migueldeicaza/SwiftTerm. Retry once the network is up.

App will not open / “damaged”

That is Gatekeeper, not a broken download. Right-click the app in Applications and choose Open, or run xattr -cr "/Applications/Terminal Organizer.app".
